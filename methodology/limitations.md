# Limitations

AI-agent runs are nondeterministic and this repository does not claim scientific certainty or a universal leaderboard. Comparisons can be affected by small sample sizes, model architecture, hidden provider behavior, agent context systems, tool implementations, environment/configuration differences, network/tool availability, timing variability, and different implementation paths.

Context occupancy is not billing. Provider quota percentages can be coarse, delayed, asynchronous, and provider-specific; they are not exact token counts and cannot be treated as cross-provider equivalents.

## Original Codex-study confounder

Trials A and B added additional tests during their runs. Trials C and D did not. Their direct quota/context comparison is therefore behaviorally confounded in addition to the limitations above. The study is preserved as an exploratory observation, not proof of causation.
